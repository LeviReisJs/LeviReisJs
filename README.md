### ✦ um pouco sobre mim ✦

</div>

Desenvolvedor **backend** com foco em **Ruby on Rails** e segurança de API, e estudante de **Odontologia**. Construo sistemas nos dois mundos: APIs em produção para um provedor de internet e software clínico que ajuda dentista a decidir com segurança na cadeira.

O que costuma aparecer no meu código: **API-only**, autenticação **JWT assinado**, **RLS no Postgres**, multi-tenant, cadeia de custódia com *audit trigger*, rate limiting e *quality gate* no CI. Tudo roda em **Docker**, com deploy via **Coolify**.

**No que estou trabalhando:**

- 🦷 **OdontoDose** — cálculo seguro de dose de anestésico local (PWA + app + portal)
- ⚖️ **Mofebites** — relatórios de perícia odontolegal, Flutter + Rails + Supabase
- 🎟️ **TRIIX** — backend Rails do clube de benefícios e app Flutter do assinante
- 🧠 **cerebro-odonto** — vault de referência odontológica com busca semântica
- 🔌 **mcp-openi-server** — MCP server open source para imagens médicas do NLM
